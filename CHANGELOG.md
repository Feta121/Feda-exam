# Changelog

## Round 1 corrections
- Logo: favicon (shield mark, cropped from the supplied logo) and the whole logo picture at the top of the sidebar.
- Practice mode: clicking an option shows the result and explanation immediately; the Submit button was removed.
- Mock exam: new "Questions per page" option (1, 2, 3, 5, 10, 20), default 5. Saved with the exam, so a reload returns to the same page.

## Round 2 corrections
- Practice mode: the Next question (or Skip) button moved from under the explanation to a bar pinned at the top of the question, so it stays in view while scrolling. Enter or the right arrow also moves on once an answer is shown, and the page returns to the new question automatically.

## Round 3 corrections
- Exam page header on phones: two tidy rows (logo + title + timer, then progress + Questions/Submit); nothing wraps into a vertical column.
- Light theme is now the default on every device; dark is used only after the student switches to it.
- The full logo picture now appears on the loading screens (instant splash before the app loads, and the "Loading question bank" screen).

## Round 4 corrections
- Added 34 questions from seniors_.docx (ids SEN-001 to SEN-034) as a new source, "Seniors' Questions". Their answers and explanations are the ones written in the document. No duplicates of existing questions were found.
- New Sources page: each source has its first-page picture, a description, counts, and practise / mock-exam buttons. Tapping the picture lists the titles inside it (chapters for the two books that have them) with a Practise button for each title.
- Practice has a new Source filter, and the mock exam setup has a new "By source" type (a whole source, or one of its titles).

## Round 5 corrections
- Sources page on phones: the description and the Practise all / Mock exam / Show titles buttons now use the full card width under the picture, instead of staying squeezed beside it. Wide screens are unchanged.

## Round 6 corrections
- Shared cases: 20 groups of questions in Lippincott's (chapters 14, 16 and 17; 65 questions) that share a case ("Questions 55 to 58: A 30-year-old ...") now carry that case with every question. It appears above the question wherever it is shown (exam, practice, results review), so it still makes sense when the questions are shuffled or only some of them appear.
- The case text had been stuck to the end of the previous question's last answer option; it was separated out and the options cleaned. Stray "Directions" fragments in three Comprehensive Review options were removed.
- The gestational age in the questions 55-58 case now reads 34¹ weeks as printed in the book (the PDF text had flattened it to "341").
- Admin: the question editor has a "Shared case" box, and the search also looks inside cases.
