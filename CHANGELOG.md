# Changelog

## Round 1 corrections
- Logo: favicon (shield mark, cropped from the supplied logo) and the whole logo picture at the top of the sidebar.
- Practice mode: clicking an option shows the result and explanation immediately; the Submit button was removed.
- Mock exam: new "Questions per page" option (1, 2, 3, 5, 10, 20), default 5. Saved with the exam, so a reload returns to the same page.

## Round 2 corrections
- Practice mode: the Next question (or Skip) button moved from under the explanation to a bar pinned at the top of the question, so it stays in view while scrolling. Enter or the right arrow also moves on once an answer is shown, and the page returns to the new question automatically.
